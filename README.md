# Aim-Practice-Game-
In this game, there will be two sets of circles, green and red. The green circles are the targets that the user has to click before the time runs out in the round. The red circles are the bombs, and the user cannot click them, or else the game will be over. If the user clicks all the green targets before the round ends, then the next round will start with a new set of targets and bombs. 
There are also some difficulty scales as the user progresses to higher stages. These include more targets to click and bombs to avoid, less time to click all the targets, and smaller targets and larger bombs. The point of the game is to see how far the user can get through the rounds to help train their aim and achieve the highest score they possibly can.
